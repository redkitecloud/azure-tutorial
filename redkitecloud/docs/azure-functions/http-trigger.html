HTTP Trigger — Build an API with Azure Functions

The HTTP trigger is the most commonly used Azure Functions trigger — it turns a function into a REST API endpoint. When an HTTP request hits the function URL, your code executes and returns a response. It's the fastest way to build a serverless API that scales automatically and costs nothing when idle.

Authorization Levels

HTTP triggers have three authorization levels controlling who can call the function:

LevelAccessKey RequiredUse When
AnonymousAnyone — no authenticationNonePublic APIs, webhooks
FunctionCaller must provide a function-level keyFunction keyInternal APIs, restrict to known clients
AdminCaller must provide the master host keyMaster keyAdmin operations only
ℹ️
Passing Keys Function keys are passed in the URL as a query parameter (?code=YOUR_KEY) or in the x-functions-key header. Never expose function keys in client-side JavaScript — use anonymous or Azure AD authentication for browser-facing APIs.

HTTP Methods

Specify which HTTP methods the trigger accepts. By default HTTP triggers accept GET and POST. You can restrict to specific methods:

PythonHTTP trigger — GET and POST only
import azure.functions as func
import json

app = func.FunctionApp(http_auth_level=func.AuthLevel.ANONYMOUS)

@app.route(route="products", methods=["GET", "POST"])
def products(req: func.HttpRequest) -> func.HttpResponse:
    if req.method == "GET":
        # Return list of products
        products = [{"id": 1, "name": "Widget"}, {"id": 2, "name": "Gadget"}]
        return func.HttpResponse(
            json.dumps(products),
            mimetype="application/json",
            status_code=200
        )
    elif req.method == "POST":
        body = req.get_json()
        # Create product logic here
        return func.HttpResponse(
            json.dumps({"created": True, "id": 3}),
            mimetype="application/json",
            status_code=201
        )

Route Parameters and Query Strings

PythonRoute parameters and query strings
@app.route(route="products/{productId}")   # {productId} is a route parameter
def get_product(req: func.HttpRequest) -> func.HttpResponse:
    # Get route parameter
    product_id = req.route_params.get("productId")

    # Get query string parameter: /products/123?include=details
    include = req.params.get("include", "basic")

    return func.HttpResponse(
        json.dumps({"id": product_id, "detail_level": include}),
        mimetype="application/json"
    )

Request and Response

Reading the Request

  • req.method — HTTP method (GET, POST, PUT, DELETE)
  • req.params — Query string parameters dict
  • req.route_params — Route template parameters dict
  • req.headers — Request headers
  • req.get_body() — Raw body as bytes
  • req.get_json() — Parse body as JSON

Building the Response

PythonResponse examples
# 200 OK with JSON body
return func.HttpResponse(json.dumps(data), mimetype="application/json", status_code=200)

# 201 Created
return func.HttpResponse(json.dumps({"id": new_id}), mimetype="application/json", status_code=201)

# 400 Bad Request
return func.HttpResponse("Missing required field: name", status_code=400)

# 404 Not Found
return func.HttpResponse("Product not found", status_code=404)

# 500 Internal Server Error
return func.HttpResponse("Internal error", status_code=500)

CORS Configuration

If your HTTP function is called from a browser (JavaScript frontend), you need to configure CORS (Cross-Origin Resource Sharing) to allow requests from your frontend domain.

Azure CLIConfigure CORS for a Function App
az functionapp cors add \
  --name myfunctionapp-2026 \
  --resource-group myRG \
  --allowed-origins "https://www.contoso.com" "https://app.contoso.com"

# Allow all origins (dev only — not recommended for production)
az functionapp cors add \
  --name myfunctionapp-2026 \
  --resource-group myRG \
  --allowed-origins "*"

Full API Example

A complete serverless REST API for a products resource:

Pythonproducts_api/function_app.py
import azure.functions as func
import json

app = func.FunctionApp(http_auth_level=func.AuthLevel.FUNCTION)

# In-memory store (replace with database in production)
products_db = {
    "1": {"id": "1", "name": "Widget", "price": 9.99},
    "2": {"id": "2", "name": "Gadget", "price": 24.99},
}

@app.route(route="products", methods=["GET"])
def list_products(req: func.HttpRequest) -> func.HttpResponse:
    return func.HttpResponse(
        json.dumps(list(products_db.values())),
        mimetype="application/json"
    )

@app.route(route="products/{id}", methods=["GET"])
def get_product(req: func.HttpRequest) -> func.HttpResponse:
    product_id = req.route_params.get("id")
    product = products_db.get(product_id)
    if not product:
        return func.HttpResponse("Not found", status_code=404)
    return func.HttpResponse(json.dumps(product), mimetype="application/json")

@app.route(route="products", methods=["POST"])
def create_product(req: func.HttpRequest) -> func.HttpResponse:
    try:
        body = req.get_json()
        new_id = str(len(products_db) + 1)
        body["id"] = new_id
        products_db[new_id] = body
        return func.HttpResponse(json.dumps(body), mimetype="application/json", status_code=201)
    except ValueError:
        return func.HttpResponse("Invalid JSON", status_code=400)
