Azure Functions Pricing

Azure Functions pricing depends heavily on which hosting plan you choose. Consumption plan is nearly free for low-volume workloads thanks to a generous free tier. Premium plan has a fixed minimum monthly cost. Dedicated plan charges by the hour like App Service. Understanding each model prevents billing surprises and helps you choose the right plan for your workload.

Consumption Plan Pricing

The Consumption plan has two billing dimensions — executions and GB-seconds (memory × time):

DimensionFree Tier (monthly)Price Beyond Free
Executions1,000,000 executions~₹17 per million executions
GB-seconds400,000 GB-seconds~₹1.40 per 100,000 GB-seconds
💡
GB-Seconds Explained GB-seconds = memory used (GB) × execution duration (seconds). A function using 512 MB (0.5 GB) for 2 seconds = 1 GB-second. The free tier's 400,000 GB-seconds = a 512 MB function running for ~222 hours/month — very generous.

Premium Minimum Cost Even with zero executions, Premium plan charges for the pre-warmed instance. EP1 minimum cost is ~₹5,500/month. This is the "always warm" tax — you're paying for guaranteed availability.

Functions vs App Service Breakeven

At what traffic volume does Consumption plan become more expensive than an App Service Basic B1 (~₹1,200/month)?

  • B1 costs ~₹1,200/month flat regardless of traffic
  • Consumption at ~100M executions/month (300ms, 256 MB) costs ~₹1,500
  • Breakeven: roughly 80–100 million executions/month

Below that level, Consumption is cheaper. Above it, Dedicated becomes more cost-effective.

Top 7 Cost-Saving Tips

1. Stay Within the Free Tier

1 million executions + 400,000 GB-seconds free every month. Low-volume functions often cost nothing.

2. Reduce Memory Allocation

GB-seconds = memory × time. Reducing memory from 512 MB to 128 MB for a function that doesn't need it cuts GB-second cost by 75%.

3. Optimise Function Duration

Shorter execution = fewer GB-seconds. Optimise slow queries, use async patterns, avoid unnecessary waits.

4. Use Consumption for Sporadic Workloads

Timer jobs, webhook processors, and batch jobs that run infrequently are almost always cheapest on Consumption.

5. Use Dedicated Plan if You Already Have App Service

Adding Functions to an existing App Service Plan is free — the plan is already paid for.

6. Right-Size Premium Plan Instances

Don't use EP3 if EP1 is sufficient. Monitor actual CPU and memory usage before choosing Premium SKU.

7. Monitor with Azure Cost Analysis

Check monthly Functions cost breakdowns — execution count, GB-seconds, and plan costs — in Azure Cost Management. Set budget alerts before costs spike.
