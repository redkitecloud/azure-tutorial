Blob Storage Trigger

The Blob Storage trigger fires your function whenever a file is created or updated in an Azure Blob Storage container. It's the standard pattern for file processing pipelines — a user uploads an image, CSV, or document, and your function automatically processes it. No polling, no queues to manage — Azure handles the event detection for you.

How the Blob Trigger Works

The Blob trigger uses Azure Storage's blob change feed or polling to detect new/updated blobs. When a matching blob is created or updated:

  1. Azure detects the new blob in the monitored container/path
  2. Azure passes the blob content and metadata to your function
  3. Your function processes the file
  4. Results can be written to another blob, database, or queue via output bindings
⚠️
Blob Trigger Latency On the Consumption plan, Blob triggers can have up to 10 minutes of latency — Azure polls for new blobs rather than reacting instantly. For near-real-time processing, use an Event Grid trigger instead (fires within seconds). On Premium and Dedicated plans, latency is much lower.

Path Patterns

The path pattern defines which blobs trigger the function:

Path PatternsBlob trigger path examples
uploads/{name}              # Any blob in "uploads" container
uploads/{name}.{ext}        # Blobs with any extension — ext captures extension
uploads/images/{name}.jpg   # Only .jpg files in uploads/images/
uploads/{blobname}          # Capture full blob name including path

Blob Trigger and Bindings

PythonBlob trigger — process uploaded CSV
import azure.functions as func
import logging
import csv
import io

app = func.FunctionApp()

@app.blob_trigger(arg_name="inputBlob",
                  path="uploads/{name}",
                  connection="AzureWebJobsStorage")
@app.blob_output(arg_name="outputBlob",
                 path="processed/{name}",
                 connection="AzureWebJobsStorage")
def process_csv(inputBlob: func.InputStream,
                outputBlob: func.Out[str]) -> None:

    # Read the uploaded CSV
    content = inputBlob.read().decode("utf-8")
    reader = csv.DictReader(io.StringIO(content))

    # Process rows
    results = []
    for row in reader:
        # Apply transformation logic
        row["processed"] = True
        results.append(row)

    # Write processed data to output container
    output = csv.DictWriter(io.StringIO(), fieldnames=results[0].keys())
    output_str = io.StringIO()
    writer = csv.DictWriter(output_str, fieldnames=results[0].keys())
    writer.writeheader()
    writer.writerows(results)
    outputBlob.set(output_str.getvalue())

    logging.info(f"Processed {len(results)} rows from {inputBlob.name}")

Accessing Blob Metadata

The InputStream object provides useful metadata about the blob:

  • inputBlob.name — Full blob path (e.g., uploads/myfile.csv)
  • inputBlob.length — File size in bytes
  • inputBlob.uri — Full blob URI
  • inputBlob.read() — Read entire content as bytes

Blob Trigger vs Event Grid Trigger

Blob TriggerEvent Grid Trigger
Latency (Consumption)Up to 10 minutesNear-instant (seconds)
Setup complexitySimple — just configure pathMore complex — needs Event Grid subscription
Missed eventsHandles missed events via pollingMay miss events if function is down
Best forNon-time-sensitive processing, batchReal-time processing, customer-facing

Real Example — Image Processing Pipeline

PythonAuto-generate thumbnail on image upload
import azure.functions as func
from PIL import Image
import io

app = func.FunctionApp()

@app.blob_trigger(arg_name="image",
                  path="images/{name}",
                  connection="AzureWebJobsStorage")
@app.blob_output(arg_name="thumbnail",
                 path="thumbnails/{name}",
                 connection="AzureWebJobsStorage")
def generate_thumbnail(image: func.InputStream,
                       thumbnail: func.Out[bytes]) -> None:
    # Open original image
    img = Image.open(io.BytesIO(image.read()))

    # Resize to thumbnail
    img.thumbnail((200, 200))

    # Save to bytes
    output = io.BytesIO()
    img.save(output, format=img.format or "JPEG")
    thumbnail.set(output.getvalue())

    logging.info(f"Thumbnail created for {image.name}")
