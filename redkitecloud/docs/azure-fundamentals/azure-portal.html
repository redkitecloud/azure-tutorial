Azure Portal Walkthrough

The Azure Portal is your web-based control centre for everything in Azure. Every resource you create, every setting you change, every bill you check — it all happens through the portal. Whether you're a developer, an architect, or an administrator, the portal is the first tool you'll open every day. This page walks you through every section so you know exactly where everything is.

What is the Azure Portal?

The Azure Portal is a web-based, unified management console for Microsoft Azure. It provides a graphical user interface (GUI) to manage all your Azure resources — virtual machines, databases, storage accounts, networks, security settings, billing, and everything else — without writing a single line of code.

Think of it as the dashboard for your entire cloud infrastructure. Everything Azure can do, you can do through the portal — albeit sometimes more efficiently via CLI or PowerShell for repetitive tasks.

ℹ️
Portal vs CLI vs PowerShell The portal is best for learning, exploration, and one-off tasks. For automation, scripting, and repeatable deployments, Azure CLI and PowerShell are faster. All three tools can do the same things — just in different ways.

Accessing the Portal

The Azure Portal is accessible from any modern web browser. No installation required.

URL Azure Portal 
https://portal.azure.com

Sign in with your Microsoft account (personal) or your Azure Active Directory / Entra ID account (work/school). If you have a free account, sign in with the Microsoft account you used to create it.

💡
Mobile Access Azure also has a mobile app for iOS and Android — Microsoft Azure. It gives you a simplified portal experience on your phone, ideal for monitoring and alerts while you're away from your desk.

The Home Page

The Home page is what you see immediately after logging in. It contains several useful sections:

Azure Services Row

A quick-access row of the most commonly used Azure services — Virtual Machines, Storage Accounts, SQL Databases, App Services, and more. Click any icon to go directly to that service's blade.

Recent Resources

Shows the last resources you visited or created. Extremely useful for quickly jumping back to something you were working on. Azure remembers your last 20 visited resources.

Navigate Section

Quick links to key portal areas: Subscriptions, Resource Groups, All Resources, and Dashboard. These are the four most-visited locations in the portal for most users.

Useful Links and Tools

Links to Azure documentation, tutorials, and pricing calculator — useful when you're learning or planning costs.

💡
Pro Tip You can switch between Home view and Dashboard view using the toggle at the top left. Dashboards are customisable — you can pin any resource, metric, or chart to your dashboard for a personalised overview.

Global Search

The search bar at the top of every portal page is one of the most powerful features. You can use it to:

  • Find any Azure service by name (e.g., type "virtual machine" to go directly to VM creation)
  • Search for specific resources you've already created (e.g., find your VM named "myVM-prod")
  • Search documentation and marketplace items
  • Navigate to portal settings and features
💡
Keyboard Shortcut Press G then / (or just click the search bar) to jump straight to global search from anywhere in the portal. This is the fastest way to navigate.

Resource Groups in the Portal

Resource Groups are one of the most important concepts in Azure — and the portal makes them easy to work with. A Resource Group is a logical container that holds related Azure resources. Think of it as a folder for your cloud resources.

Why Resource Groups Matter

  • Every Azure resource must belong to exactly one Resource Group
  • You can delete a Resource Group to delete all resources inside it at once — very useful for cleaning up test environments
  • You can apply access control (RBAC) and tags at the Resource Group level
  • Resources in a group don't have to be in the same region
💡
Naming Convention A good naming convention: rg-[project]-[environment]-[region]
Example: rg-webapp-prod-centralindia or rg-api-dev-eastus

Creating Your First Resource

Creating any resource in the Azure Portal follows the same pattern — a multi-step wizard called a Create blade.

Step-by-Step: Create a Resource Group

Let's walk through creating a Resource Group — the simplest resource and the first thing you create before anything else.

  1. In the portal, click Resource groups in the left sidebar (or search for it)
  2. Click + Create at the top
  3. Select your Subscription
  4. Enter a Resource group name (e.g., rg-learning-centralindia)
  5. Select a Region — choose Central India for Indian workloads
  6. Click Review + create
  7. Review the summary, then click Create

Your Resource Group is created in seconds and appears in the Resource groups list.

ℹ️
Review + Create Pattern Almost every resource creation in Azure ends with a "Review + create" tab. This shows you a summary of everything you've configured and runs validation. Azure checks for errors before you deploy. If validation fails, it highlights exactly what needs to be fixed.

Notifications & Activity Log

The bell icon (🔔) in the top navigation bar shows all recent portal notifications — resource deployments, alerts, policy violations, and more. Click it to see the status of recent operations.

For a complete history of everything that happened in your subscription, go to Monitor → Activity Log. This shows every create, update, and delete operation across all resources — who did it, when, and the result.

💡
Deployment Failures If a resource deployment fails, click the notification to see the detailed error message. Azure gives very specific error reasons — missing quotas, naming conflicts, policy violations — so you know exactly what to fix.

Cloud Shell in the Portal

The terminal icon (>_) in the top navigation bar opens Azure Cloud Shell — a fully functional terminal built directly into the browser. No installation, no configuration. Choose between Bash (Azure CLI) or PowerShell and start running commands immediately.

Cloud Shell comes with:

  • Azure CLI pre-installed and authenticated
  • Azure PowerShell pre-installed
  • 5 GB of persistent storage (for scripts and files)
  • Common tools: git, kubectl, terraform, python, and more
💡
First Time Setup The first time you open Cloud Shell, Azure will ask you to create a storage account to persist your files. Choose your subscription and a region close to you — Central India works well. This is a one-time setup.

Customising the Portal

The Azure Portal is highly customisable. Here are the most useful customisation options:

Favourites

In the left sidebar, right-click any item to pin/unpin it, or go to All Services and click the star next to any service. Your favourites appear at the top of the sidebar for one-click access.

Dashboards

Click Dashboard in the portal to create a personalised view. Pin any resource, chart, metric, or service tile to your dashboard. You can have multiple dashboards — one for production monitoring, one for cost tracking, one for a specific project.

Portal Settings

Click the gear icon (⚙️) in the top right to access portal settings:

  • Appearance — Light or dark mode
  • Language & Region — Change the portal language
  • Timeout — Set an inactivity timeout for security
  • Startup page — Choose between Home and Dashboard as your landing page
💡
AZ-900 Exam Tip The exam may ask what the Azure Portal is, how resources are managed in it, and what tools it provides. Key facts: web-based GUI at portal.azure.com · no installation required · accessible from any browser · includes Cloud Shell · supports dashboards and customisation.
