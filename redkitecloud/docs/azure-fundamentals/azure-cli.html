Azure CLI — Complete Guide

The Azure Portal is great for learning and exploration, but when you need to create 50 virtual machines, automate a deployment pipeline, or write a script that runs every night — you need the Azure CLI. It's fast, scriptable, cross-platform, and once you learn the pattern, every command feels intuitive. This guide takes you from installation to confident everyday usage.

What is the Azure CLI?

The Azure CLI (Command-Line Interface) is a cross-platform tool that lets you manage Azure resources from a terminal. It runs on Windows, macOS, and Linux. You type commands, Azure executes them, and results come back as text (or JSON).

ℹ️
CLI vs Portal vs PowerShell All three can do the same things. The Portal is best for visual exploration. Azure CLI is best for Bash scripting, Linux environments, and developers. Azure PowerShell is best for Windows administrators and those already using PowerShell. On this site, we primarily use Azure CLI.

Installing the Azure CLI

Windows

PowerShell Install via MSI (recommended for Windows) 
# Download and run the MSI installer
# Visit: https://aka.ms/installazurecliwindows
# OR install via winget:
winget install Microsoft.AzureCLI

macOS

Bash Install via Homebrew 
brew update && brew install azure-cli

Linux (Ubuntu / Debian)

Bash Install on Ubuntu/Debian 
curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash

Verify Installation

Bash Check installed version 
az version
💡
No Installation? Use Cloud Shell If you don't want to install anything locally, use Azure Cloud Shell at portal.azure.com. It has the latest Azure CLI pre-installed and authenticated — perfect for learning.

Signing In

Interactive Login (Most Common)

Bash Login to Azure 
az login

This opens a browser window for you to sign in with your Microsoft account. Once signed in, the terminal shows a list of your subscriptions.

Check Currently Signed-In Account

Bash Show current account 
az account show

List All Subscriptions

Bash List subscriptions 
az account list --output table

Switch Active Subscription

Bash Set active subscription 
az account set --subscription "My Subscription Name"
# OR using subscription ID:
az account set --subscription "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

Command Structure Explained

Every Azure CLI command follows the same pattern. Once you understand it, any command becomes readable:

Structure Azure CLI command pattern 
az [group] [subgroup] [command] [--parameter value]

# Examples:
az vm create ...          # group=vm, command=create
az storage account list   # group=storage, subgroup=account, command=list
az network vnet show ...  # group=network, subgroup=vnet, command=show
PartMeaningExample
azThe CLI tool itselfaz
[group]The Azure service or resource typevm, storage, network
[subgroup]Sub-resource within the serviceaccount, vnet, nsg
[command]The action to performcreate, list, show, delete
--parameterOptions and values--name myVM --location centralindia
💡
Built-in Help Add --help to any command to see all available parameters and examples. Works at any level: az --help, az vm --help, az vm create --help.

Essential Commands

Resource Groups

Bash Resource Group commands 
# Create a resource group
az group create --name myResourceGroup --location centralindia

# List all resource groups
az group list --output table

# Show details of a resource group
az group show --name myResourceGroup

# Delete a resource group (and ALL resources inside it)
az group delete --name myResourceGroup --yes --no-wait

Virtual Machines

Bash VM commands 
# Create a Linux VM
az vm create \
  --resource-group myResourceGroup \
  --name myVM \
  --image Ubuntu2204 \
  --size Standard_B2s \
  --admin-username azureuser \
  --generate-ssh-keys \
  --location centralindia

# List VMs in a resource group
az vm list --resource-group myResourceGroup --output table

# Start a VM
az vm start --resource-group myResourceGroup --name myVM

# Stop a VM (deallocated — stops billing)
az vm deallocate --resource-group myResourceGroup --name myVM

# Delete a VM
az vm delete --resource-group myResourceGroup --name myVM --yes

Storage Accounts

Bash Storage commands 
# Create a storage account
az storage account create \
  --name mystorageaccount \
  --resource-group myResourceGroup \
  --location centralindia \
  --sku Standard_LRS

# List storage accounts
az storage account list --output table

# Delete a storage account
az storage account delete --name mystorageaccount \
  --resource-group myResourceGroup --yes

Output Formats

Azure CLI can return results in different formats using the --output (or -o) flag:

FormatFlagBest For
JSON--output jsonDefault. Full details, good for scripting
Table--output tableHuman-readable, easy to scan
YAML--output yamlReadable structured format
TSV--output tsvTab-separated, good for piping to scripts
None--output noneSuppress all output
Bash Output format examples 
az vm list --output table      # Clean table view
az vm list --output json       # Full JSON
az vm list --output tsv        # Tab-separated for scripts

Querying Output with JMESPath

The --query flag lets you filter and transform CLI output using JMESPath syntax — a query language for JSON. This is incredibly powerful for extracting specific values from responses.

Bash JMESPath query examples 
# Get just the name and location of all VMs
az vm list --query "[].{Name:name, Location:location}" --output table

# Get the public IP of a specific VM
az vm show \
  --resource-group myResourceGroup \
  --name myVM \
  --query "publicIps" \
  --output tsv

# Get only running VMs
az vm list \
  --query "[?powerState=='VM running'].name" \
  --output table

Real-World Examples

Deploy a Complete Web App Stack

Bash Create RG + App Service Plan + Web App 
# 1. Create resource group
az group create --name rg-webapp-prod --location centralindia

# 2. Create App Service Plan (PaaS)
az appservice plan create \
  --name asp-webapp-prod \
  --resource-group rg-webapp-prod \
  --sku B1 \
  --is-linux

# 3. Create Web App
az webapp create \
  --resource-group rg-webapp-prod \
  --plan asp-webapp-prod \
  --name my-webapp-redkite \
  --runtime "NODE:18-lts"

# 4. Open the app in browser
az webapp browse \
  --resource-group rg-webapp-prod \
  --name my-webapp-redkite

Tips & Best Practices

  • Always set a default location — az configure --defaults location=centralindia so you don't have to type --location every time
  • Always set a default resource group — az configure --defaults group=myResourceGroup
  • Use --no-wait — For long operations like VM creation, add --no-wait to return immediately and let it run in the background
  • Use --yes or -y — Skip confirmation prompts in scripts
  • Update regularly — az upgrade keeps the CLI up to date
💡
AZ-900 Exam Tip For the exam, know what the Azure CLI is (cross-platform command-line tool), that it uses the az command, that it can run in Cloud Shell without installation, and that it's an alternative to the Portal and PowerShell for managing Azure resources.
