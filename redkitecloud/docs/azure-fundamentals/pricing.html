Azure Pricing & Free Tier

One of the most important skills in cloud computing is understanding how you're billed — and how to keep costs under control. Azure's pricing model is flexible and powerful, but it can also be complex. This page demystifies Azure pricing from the ground up: the free tier, pay-as-you-go, reserved instances, spot pricing, and the tools Azure gives you to estimate and manage costs.

The Azure Free Account

When you sign up for Azure for the first time, you get a free account that includes three layers of free usage:

LayerWhat You GetDuration
Credit$200 (approx. ₹16,600) in Azure creditsFirst 30 days only
Popular free servicesLinux VMs (B1s), Windows VMs (B1s), SQL Database (250GB), Blob Storage (5GB), and more12 months
Always-free services25+ services with permanent free tiersForever
⚠️
After 30 Days / Credits Run Out Once your $200 credit is used or 30 days pass, your account converts to pay-as-you-go. You won't be charged automatically — Azure requires you to explicitly upgrade. The 12-month free services and always-free services continue regardless.

Always-Free Services

These services have a permanent free tier that never expires — even after your free account period ends:

ServiceFree Limit

Azure App Service10 web, mobile, or API apps (F1 tier)
Azure Cosmos DB1,000 RU/s throughput + 25 GB storage
Azure Kubernetes Service (AKS)Free cluster management (pay only for VMs)

Azure Active Directory (Entra ID)500,000 objects free

Azure Bandwidth15 GB outbound data transfer per month
💡
Azure Functions Free Tier is Generous 1 million function executions per month is genuinely useful for small to medium workloads. Many hobby projects and small APIs run entirely within the free tier and never incur a charge.

Pay-As-You-Go Pricing

Beyond the free tier, Azure uses a pay-as-you-go (PAYG) model. You are billed for exactly what you use — to the second for compute, to the GB for storage, to the request for API calls.

There are no upfront commitments and no termination fees. You can start using a service today and stop tomorrow — paying only for those hours of usage.

ℹ️
Billing Granularity Virtual Machines are billed per second. Storage is billed per GB per month. Data transfer is billed per GB. API calls are billed per 1,000 or 1 million calls. Each service has its own billing unit — always check the pricing page for the specific service.

What Affects Your Azure Bill

Five main factors influence how much you pay in Azure:

1. Resource Type

Different resources have completely different pricing models. A VM is priced per hour of compute. A storage account is priced per GB stored. An API call is priced per request. Always check the pricing page for each specific service.

2. Region

The same VM size can cost 10–30% more in one region than another. East US is typically one of the cheapest regions. India regions are moderately priced. Always check regional pricing before committing to a deployment location.

3. Bandwidth (Data Transfer)

Inbound data to Azure is free. Outbound data (from Azure to the internet) is charged per GB. Data transfer between Azure services in the same region is free. Cross-region transfers are charged.

Data Transfer TypeCost
Inbound to AzureFree
Outbound to internet (first 15 GB/month)Free
Outbound to internet (beyond 15 GB)Charged per GB
Between services in same regionFree
Between Azure regionsCharged per GB

4. Subscription Type

Enterprise Agreement (EA) customers with large commitments get significant discounts. Pay-as-you-go customers pay list price. Microsoft partners and CSP (Cloud Solution Provider) resellers also offer discounted rates.

5. Reserved vs On-Demand

Paying upfront for 1 or 3 years (Reserved Instances) gives you up to 72% off pay-as-you-go prices. This is covered in detail in the next section.

Reserved Instances

Reserved Instances (RIs) let you commit to using a specific VM size in a specific region for 1 or 3 years — in exchange for a massive discount over pay-as-you-go pricing.

CommitmentDiscount vs PAYGPayment Options
1-year reservationUp to 40% offAll upfront, monthly, or partial upfront
3-year reservationUp to 72% offAll upfront, monthly, or partial upfront
💡
When to Use Reserved Instances If you have a workload that runs 24/7 and you know what size VM you need — Reserved Instances are almost always worth it. A VM that would cost ₹10,000/month on PAYG might cost ₹2,800/month on a 3-year reservation. The savings are enormous for stable, long-running workloads.
⚠️
Commitment Risk Reserved Instances are a commitment. If you stop using the VM, you still pay for the reservation (though you can exchange or cancel with some penalty). Only reserve capacity you're confident you'll use.

Spot Pricing

Azure Spot VMs let you use Azure's unused compute capacity at up to 90% discount compared to pay-as-you-go prices. The catch: Azure can evict (terminate) your Spot VM with 30 seconds notice when it needs the capacity back.

When to Use Spot VMs

  • Batch processing jobs that can be interrupted and resumed
  • Rendering workloads
  • Dev/test environments that can be recreated
  • CI/CD build agents
  • Any workload that is fault-tolerant and stateless
⚠️
Never Use Spot For Production web servers, databases, or any workload where sudden termination would cause user-facing downtime. Spot is for resilient, interruptible workloads only.

The Azure Pricing Calculator

Before deploying anything, use the Azure Pricing Calculator to estimate your monthly costs. It lets you configure services, choose regions, and see a cost breakdown before you spend a rupee.

URL Azure Pricing Calculator 
https://azure.microsoft.com/pricing/calculator

How to use it:

  1. Search for a service (e.g., "Virtual Machines")
  2. Configure the options — region, size, OS, hours/month
  3. Add more services as needed
  4. See total estimated monthly cost at the bottom
  5. Export the estimate as PDF or share a link

The TCO Calculator

The Total Cost of Ownership (TCO) Calculator helps you compare the cost of running workloads on-premises vs on Azure. It accounts for hardware, power, cooling, labour, and facilities costs — not just compute.

URL Azure TCO Calculator 
https://azure.microsoft.com/pricing/tco/calculator
ℹ️
Pricing Calculator vs TCO Calculator Use the Pricing Calculator to estimate what Azure will cost. Use the TCO Calculator to show your management how much you'll save by moving from on-premises to Azure.

Cost Management & Budgets

Azure Cost Management is a built-in tool in the portal that helps you monitor, analyse, and optimise your spending.

Key Features

  • Cost analysis — Break down costs by service, resource group, tag, or time period
  • Budgets — Set a monthly spending limit and get email alerts when you approach it
  • Recommendations — Azure Advisor suggests resources you can resize or shut down to save money
  • Exports — Export cost data to a storage account for custom reporting
Azure Portal Where to find Cost Management 
Portal → Search "Cost Management" → Cost Management + Billing

Cost-Saving Tips

  • Deallocate VMs when not in use — A stopped (deallocated) VM doesn't charge for compute. Use it for dev/test VMs overnight.
  • Right-size your VMs — Many teams over-provision. Azure Advisor will tell you if your VM is using less than 5% CPU — a sign you can downsize.
  • Use Reserved Instances for stable workloads — If a VM runs 24/7, reserve it for 1–3 years for up to 72% savings.
  • Use Spot for batch jobs — Up to 90% savings for fault-tolerant workloads.
  • Delete unused resources — Orphaned disks, unattached public IPs, and idle load balancers all cost money.
  • Use Azure Hybrid Benefit — If you have existing Windows Server or SQL Server licences with Software Assurance, you can use them on Azure VMs for significant savings.
  • Set budget alerts — Configure alerts at 80% and 100% of your monthly budget so surprises don't happen.
💡
AZ-900 Exam Tip Know the difference between the Pricing Calculator (estimate Azure costs) and the TCO Calculator (compare on-premises vs cloud costs). Also know the three pricing options: PAYG, Reserved Instances (1 or 3 year), and Spot pricing.
