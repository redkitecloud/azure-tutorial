Azure PowerShell

Azure PowerShell is Microsoft's scripting solution for managing Azure resources. If you come from a Windows administration background, you already know PowerShell — Azure PowerShell is simply a set of modules that adds Azure-specific commands (called cmdlets) to that familiar environment. Even if you're new to PowerShell, it's worth learning alongside the CLI, especially for enterprise Windows environments.

What is Azure PowerShell?

Azure PowerShell is a set of PowerShell modules (specifically the Az module) that provide cmdlets for managing Azure resources. You run it inside a PowerShell terminal — either Windows PowerShell (built into Windows) or the newer cross-platform PowerShell 7+ (which runs on Windows, macOS, and Linux).

ℹ️
Az Module vs AzureRM Module The original Azure PowerShell module was called AzureRM. It was replaced by the Az module in 2019. If you see tutorials using Get-AzureRmVM, they are outdated. The modern equivalent is Get-AzVM. Always use the Az module.

Azure CLI vs Azure PowerShell

Both tools can do everything — the question is which fits your workflow better.

FactorAzure CLIAzure PowerShell
LanguageBash-style commandsPowerShell cmdlets (Verb-Noun)
Best forLinux/Mac admins, developersWindows admins, enterprises
Syntaxaz vm create ...New-AzVM ...
Scripting.sh bash scripts.ps1 PowerShell scripts
OutputJSON by defaultPowerShell objects (rich)
PlatformsWindows, Mac, LinuxWindows, Mac, Linux (PS7+)
In Cloud ShellYes (Bash mode)Yes (PowerShell mode)
💡
Which Should You Learn? Learn both at a basic level. In practice, most cloud engineers prefer Azure CLI for day-to-day tasks. Windows administrators and enterprise teams often prefer PowerShell. Knowing both makes you versatile and more employable.

Installing Azure PowerShell

Windows (PowerShell 5.1 or 7+)

PowerShell Install Az module on Windows 
# Run as Administrator
Install-Module -Name Az -Repository PSGallery -Force

macOS

Bash Install PowerShell 7 + Az module on macOS 
# Install PowerShell 7 first
brew install --cask powershell

# Then open pwsh and install Az module
pwsh
Install-Module -Name Az -Repository PSGallery -Force

Linux (Ubuntu)

Bash Install PowerShell 7 + Az module on Ubuntu 
# Install PowerShell 7
sudo snap install powershell --classic

# Launch PowerShell and install Az module
pwsh
Install-Module -Name Az -Repository PSGallery -Force

Verify Installation

PowerShell Check Az module version 
Get-Module -Name Az -ListAvailable

Signing In

Interactive Login

PowerShell Sign in to Azure 
Connect-AzAccount

This opens a browser for authentication. After signing in, PowerShell shows a list of your subscriptions.

Check Current Account

PowerShell Get current context 
Get-AzContext

List and Switch Subscriptions

PowerShell Manage subscriptions 
# List all subscriptions
Get-AzSubscription

# Switch to a specific subscription
Set-AzContext -SubscriptionName "My Subscription"
# OR by ID:
Set-AzContext -SubscriptionId "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"

Cmdlet Structure Explained

PowerShell commands are called cmdlets (pronounced "command-lets"). They always follow a Verb-Noun pattern, making them very readable and predictable.

Structure Azure PowerShell cmdlet pattern 
[Verb]-Az[Noun] -Parameter Value

# Examples:
New-AzResourceGroup      # New (create) + Az + ResourceGroup
Get-AzVM                 # Get (read) + Az + VM
Remove-AzStorageAccount  # Remove (delete) + Az + StorageAccount
Start-AzVM               # Start (action) + Az + VM
VerbActionExample
New-AzCreate a resourceNew-AzResourceGroup
Get-AzRead/list a resourceGet-AzVM
Set-AzUpdate a resourceSet-AzVMSize
Remove-AzDelete a resourceRemove-AzResourceGroup
Start-AzStart a resourceStart-AzVM
Stop-AzStop a resourceStop-AzVM

Essential Cmdlets

Resource Groups

PowerShell Resource Group cmdlets 
# Create a resource group
New-AzResourceGroup -Name "myResourceGroup" -Location "centralindia"

# List all resource groups
Get-AzResourceGroup | Format-Table

# Delete a resource group (and all resources inside)
Remove-AzResourceGroup -Name "myResourceGroup" -Force

Virtual Machines

PowerShell VM cmdlets 
# List all VMs in a resource group
Get-AzVM -ResourceGroupName "myResourceGroup"

# Start a VM
Start-AzVM -ResourceGroupName "myResourceGroup" -Name "myVM"

# Stop and deallocate a VM (stops billing)
Stop-AzVM -ResourceGroupName "myResourceGroup" -Name "myVM" -Force

# Get VM status
Get-AzVM -ResourceGroupName "myResourceGroup" -Name "myVM" -Status

Storage Accounts

PowerShell Storage cmdlets 
# Create a storage account
New-AzStorageAccount `
  -ResourceGroupName "myResourceGroup" `
  -Name "mystorageaccount" `
  -Location "centralindia" `
  -SkuName "Standard_LRS"

# List storage accounts
Get-AzStorageAccount | Format-Table

# Delete a storage account
Remove-AzStorageAccount `
  -ResourceGroupName "myResourceGroup" `
  -Name "mystorageaccount" -Force

Writing PowerShell Scripts

One of PowerShell's biggest strengths is scripting. You can save commands in a .ps1 file and run them repeatedly. Here's a well-structured script example:

PowerShell deploy-environment.ps1 
# deploy-environment.ps1
# Creates a complete dev environment

param(
  [string]$Environment = "dev",
  [string]$Location = "centralindia"
)

$rgName = "rg-webapp-$Environment"

# Create Resource Group
Write-Host "Creating Resource Group: $rgName"
New-AzResourceGroup -Name $rgName -Location $Location -Force

# Create Storage Account
$storageName = "stwebapp$Environment"
Write-Host "Creating Storage Account: $storageName"
New-AzStorageAccount `
  -ResourceGroupName $rgName `
  -Name $storageName `
  -Location $Location `
  -SkuName "Standard_LRS"

Write-Host "Deployment complete!"
PowerShell Run the script 
.\deploy-environment.ps1 -Environment "staging" -Location "centralindia"

Real-World Examples

Stop All VMs in a Resource Group (Cost Saving)

PowerShell Stop all VMs in a resource group 
# Stop and deallocate all VMs in a resource group
# Run this every evening to save cost on dev/test VMs
$vms = Get-AzVM -ResourceGroupName "rg-dev"
foreach ($vm in $vms) {
  Write-Host "Stopping VM: $($vm.Name)"
  Stop-AzVM -ResourceGroupName "rg-dev" -Name $vm.Name -Force
}
Write-Host "All VMs stopped. Billing halted."
💡
AZ-900 Exam Tip Know what Azure PowerShell is (the Az module for managing Azure from PowerShell), that cmdlets use Verb-Noun syntax, that it works in Cloud Shell, and that it's best suited for Windows administrators. The exam won't ask you to memorise specific cmdlets.
