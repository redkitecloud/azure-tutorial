Microsoft Defender for Cloud

Microsoft Defender for Cloud is a Cloud Security Posture Management (CSPM) and Cloud Workload Protection Platform (CWPP). It continuously assesses your Azure resources against security best practices, gives you a Secure Score, and provides threat detection and alerts when attacks are underway. It is the central security dashboard for Azure.

What is Defender for Cloud?

Defender for Cloud has two main capabilities:

CapabilityWhat it Does
CSPM (Cloud Security Posture Management)Assess and improve your security posture — Secure Score, recommendations, compliance. Free tier available.
CWPP (Cloud Workload Protection Platform)Detect and respond to threats against VMs, containers, databases, storage, Key Vault. Paid Defender plans.

Secure Score

Secure Score is a percentage (0–100%) that measures how well your Azure environment follows security best practices. Higher is better.

  • Each recommendation has a point value based on its security impact
  • Implementing recommendations increases your score
  • Score is calculated: points achieved / max possible points
  • Visible per subscription, management group, or overall
ℹ️
Secure Score Goal Microsoft recommends targeting at least 60% Secure Score for a reasonable baseline. High-security environments should aim for 70%+. A score of 100% is theoretical — some recommendations may not apply to your workload.

Security Recommendations

Defender for Cloud analyses your resources and generates recommendations. Each recommendation includes:

  • Description — What the issue is
  • Affected resources — Which resources have the issue
  • Severity — High, Medium, Low
  • Remediation steps — How to fix it
  • Score impact — How many points fixing it adds
  • Quick fix — One-click remediation for many recommendations

Common high-severity recommendations:

  • Enable MFA for accounts with subscription access
  • Remove deprecated accounts from subscriptions
  • Enable disk encryption on VMs
  • Restrict RDP/SSH access (close port 3389/22 from internet)
  • Enable Azure Defender for SQL

Regulatory Compliance

The Regulatory Compliance dashboard maps your Azure resources against compliance standards — showing which controls are passing and failing:

  • Microsoft Cloud Security Benchmark (default)
  • ISO 27001
  • PCI DSS
  • HIPAA / HITRUST
  • NIST SP 800-53
  • CIS Benchmarks

Defender Plans

Enhanced threat protection requires paid Defender plans, enabled per resource type:

PlanProtectsKey Features
Defender for ServersVMs and serversJIT access, vulnerability assessment, EDR
Defender for SQLAzure SQL, SQL on VMsSQL injection detection, anomalous access
Defender for StorageStorage accountsMalware scanning, anomalous access detection
Defender for ContainersAKS, ACR, container workloadsImage vulnerability scanning, runtime threat detection
Defender for Key VaultKey VaultUnusual access patterns, credential abuse detection
Defender for App ServiceApp Service appsMalicious requests, dangling DNS detection

Security Alerts and Incidents

When Defender detects a threat, it generates a security alert with:

  • Alert severity (High, Medium, Low, Informational)
  • Affected resource
  • Attack description and tactics (MITRE ATT&CK framework)
  • Remediation steps
  • Related alerts grouped into incidents

Alerts can trigger automated responses via Logic Apps or workflow automation.

Multi-Cloud Support

Defender for Cloud extends beyond Azure — connect AWS and GCP accounts to assess and protect resources across all clouds from a single dashboard. This uses Azure Arc under the hood for non-Azure resources.

💡
AZ-104 Exam Tip Know that Defender for Cloud has free CSPM (Secure Score, recommendations) and paid CWPP (threat detection per resource type). Know that Secure Score measures security posture as a percentage. Know that regulatory compliance dashboard maps resources to standards. Know that Defender plans are per resource type.
