Users & Groups in Microsoft Entra ID

Users and groups are the building blocks of identity in Entra ID. Users represent people and services; groups collect users so you can assign permissions once rather than individually. Understanding user types, group types, and how dynamic membership works is essential for managing identity at scale.

Managing Users via CLI

Azure CLICreate and manage users
# Create a new user
az ad user create \
  --display-name "Priya Sharma" \
  --user-principal-name priya@contoso.onmicrosoft.com \
  --password "TempP@ssword123!" \
  --force-change-password-next-sign-in true

# List all users
az ad user list --output table

# Get a specific user
az ad user show --id priya@contoso.onmicrosoft.com

# Update user properties
az ad user update \
  --id priya@contoso.onmicrosoft.com \
  --job-title "Cloud Engineer" \
  --department "IT"

# Delete a user
az ad user delete --id priya@contoso.onmicrosoft.com

Group Types

Group TypeUsed ForCan Assign Azure RBAC
SecurityControl access to Azure resources, apps, policies✅ Yes
Microsoft 365Collaboration — shared mailbox, Teams, SharePoint✅ Yes (with P1/P2)
Azure CLICreate and manage groups
# Create a security group
az ad group create \
  --display-name "Cloud-Engineers" \
  --mail-nickname "cloud-engineers"

# Add member to group
az ad group member add \
  --group "Cloud-Engineers" \
  --member-id 

# List group members
az ad group member list --group "Cloud-Engineers" --output table

# Check if user is a member
az ad group member check \
  --group "Cloud-Engineers" \
  --member-id

Dynamic Groups

Dynamic groups automatically add/remove members based on rules you define on user or device attributes. Requires Entra ID P1.

Dynamic Rule ExamplesDynamic membership rule syntax
# All users in the IT department
(user.department -eq "IT")

# All users with a job title containing "Engineer"
(user.jobTitle -contains "Engineer")

# All users in India
(user.country -eq "IN")

# All users with a specific domain
(user.userPrincipalName -endsWith "@contoso.com")

# Combined rule — IT department AND based in India
(user.department -eq "IT") and (user.country -eq "IN")
💡
Dynamic Groups Save Admin Time When a new employee joins the IT department, they are automatically added to all IT groups. When they leave, they are automatically removed. No manual group membership management required.

B2B Guest Access

B2B (Business-to-Business) collaboration allows you to invite external users (from other organisations or personal email) as guests in your tenant. Guest users:

  • Use their own credentials from their home organisation
  • Are represented as Guest users in your directory
  • Can be granted access to specific apps and resources
  • Have limited directory access by default (cannot browse all users/groups)

Self-Service Password Reset (SSPR)

SSPR lets users reset their own passwords without calling the helpdesk. Requires Entra ID P1:

  • Users register authentication methods (phone, email, authenticator app)
  • When locked out, users verify identity and reset their own password
  • Reduces helpdesk calls significantly
  • Can be enabled for all users or a specific group
💡
AZ-104 Exam Tip Know the two group types (Security and Microsoft 365). Know the three membership types (Assigned, Dynamic User, Dynamic Device). Know that dynamic groups require Entra ID P1. Know that Guest users authenticate with their own home organisation credentials.
