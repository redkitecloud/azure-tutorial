AZ-104

Microsoft Azure Administrator

The most popular Azure certification — manages Azure infrastructure day-to-day

▶
Level
Associate
Questions
40–60
Duration
120 minutes
Passing Score
700 / 1000
Cost
$165 (₹13,700)
Validity
1 year (renewable)
Difficulty
★★★★★
Study Time
6–8 weeks
Who Should Take This
  • Cloud administrators managing Azure environments
  • IT professionals moving to cloud infrastructure roles
  • System administrators expanding into Azure
  • Anyone wanting a solid, well-recognised Azure credential
Prerequisites
  • AZ-900 recommended but not mandatory
  • 6+ months hands-on Azure experience recommended
  • Understanding of networking, storage, and virtualisation
Exam Topics
Manage Azure Identities (15–20%) Implement Storage (15–20%) Deploy Compute Resources (20–25%) Configure Networking (15–20%) Monitor & Backup (10–15%)
Key Skills Tested
  • Create and manage Virtual Machines, storage accounts, and VNets
  • Configure Azure Active Directory / Entra ID, users, and groups
  • Implement load balancers, VPN gateways, and network security
  • Monitor Azure resources with Azure Monitor and Log Analytics
  • Configure Azure backup and site recovery
💡 Tip: AZ-104 requires annual renewal via a free online assessment on Microsoft Learn. Don't let it expire — set a calendar reminder 2 months before expiry.
↗ Official Microsoft Page
